# Fluore

[![Website](https://img.shields.io/badge/Website-See%20it%20for%20yourself-blue)](https://fluore.pages.dev)

> A minimalist note-taking application designed for ultimate simplicity.

Fluore is a zero-friction, open-source digital notebook built for people who just want to write down their thoughts without navigating messy menus and paywalls.

---

### What Makes Fluore Different?

Combined with simple UX and blazingly fast loading times, Fluore Notes features a de-cluttered user interface with local-first note taking, allowing the user to keep data in their own hands.

---

### Features

* **Real-Time Search:** Instantly filters notes by title as you type, complete with intelligent typo handling and suggestion fallbacks.
* **Custom Color Tagging:** Organize and color-code your notes on the fly using a curated palette of pastel themes with automatic text contrast adjustment.
* **Persistent Themes:** Seamless light and dark mode switching with preference persistence via `localStorage` and zero flash of unstyled content.

### Getting Started

Since this is a lightweight static application, you don't need a complex Node.js build pipeline to run it.

1. **Clone the repository:**
```bash
git clone https://github.com/your-username/fluore.git

```


2. **Navigate to the project directory:**
```bash
cd fluore

```


3. **Run it locally:**
Simply open `index.html` in your favorite browser, or launch it using the **Live Server** extension in VS Code.
